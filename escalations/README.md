# Escalations

User escalations from the agent build system:
`escalations/<task_id>.md` (orchestration prompt §10).

An escalation is a question the agents could not answer themselves —
ambiguity, security tradeoffs, cost, irreversibility, legal risk, or intent
conflict. Conductor presents them in priority order; no agent proceeds until
the user responds.

Human contributors: escalations are public and are excellent places to learn
where the design is genuinely open.
