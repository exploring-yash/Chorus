# Clients

Thin, interchangeable clients on the Chorus protocol. The protocol is the
product; anyone may build a client (see the client spec:
[docs/spec/services/client.md](../docs/spec/services/client.md)).

| Client | Phase |
| --- | --- |
| `web/` | P1 |
| `mobile/` | P1 |
| `studio/` | P1 |

Empty during P0. The first client milestone (P1) is the identity wallet:
keys, DIDs, rotation, recovery — because nothing else works without it.
