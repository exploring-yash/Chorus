# Architecture Decision Records

An ADR is a short, dated, signed record of an irreversible decision: what we
chose, why, what we rejected, and what it costs. Format per
docs/agents/README.md (frontmatter + context/decision/consequences/rejected
alternatives). Anyone may propose an ADR; acceptance follows GOVERNANCE.md §3.
