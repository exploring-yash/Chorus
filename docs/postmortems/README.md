# Postmortems

Blameless incident postmortems: `docs/postmortems/<date>-<slug>.md`.

Rules:

- Published within 5 days of an incident.
- Focus on systems and decisions, not individuals (human or agent).
- Template: summary, timeline, impact, root causes, what went well, what went
  wrong, action items (each with an owner and a task ID).

Empty during P0.
